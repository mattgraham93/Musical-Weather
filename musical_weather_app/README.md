# 🎵 Musical Weather

A smart web application that combines weather data with music recommendations, creating personalized playlists based on current weather conditions and seasonal patterns.

## 🌟 Features

- **Weather-Based Music Recommendations**: Get music that matches your current weather
- **Seasonal Playlists**: Discover songs that fit the current season
- **Data Visualization**: Interactive charts showing weather and music correlations
- **Responsive Design**: Works great on desktop and mobile devices
- **Cloud-Native**: Deployed on Google Cloud Run for scalability

## 🚀 Quick Start

### For Local Development
```bash
# Navigate to the project
cd musical_weather_app

# Run development server
.\dev.bat dev
# or
D:/Backup/repos/Musical-Weather/.venv/Scripts/python.exe dev_main.py

# Visit: http://localhost:5000
```

### For Cloud Deployment
```bash
# Deploy to Google Cloud Run (mock mode)
.\cloud-deploy.bat

# Deploy with full functionality
.\cloud-deploy.ps1 -ProjectId YOUR_PROJECT_ID
```

## 🚀 Deployment Options

### Local Development
- **Platform**: Your machine
- **Command**: `.\dev.bat dev`
- **URL**: http://localhost:5000
- **Mode**: Development with mock data

### Google Cloud Run
- **Platform**: Google Cloud
- **Command**: `.\cloud-deploy.bat`
- **URL**: Generated by Google Cloud
- **Mode**: Production-ready

### Docker Container
- **Platform**: Any Docker host
- **Command**: `docker build -t musical-weather .`
- **Mode**: Containerized deployment
